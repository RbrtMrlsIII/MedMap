# MedMap Development Roots

## Principle
Set roots first. Build the smallest coherent slice. Improve continuously without replacing MedMap's identity or authority boundaries.

## Root chain

```text
Product intent
 ↓
Masterplan phase/slice
 ↓
Contract
 ↓
Skill
 ↓
Implementation seam
 ↓
Verification seam
 ↓
Evidence
 ↓
Full ZIP handover
```

## Content/context branching
Complex work may branch into smaller planning contexts while remaining chronologically owned by the parent slice. Example:

```text
002.S2 Camera Root
 ├─ pose model
 ├─ interruption
 ├─ wall constraints
 └─ reduced motion
```

This is planning context, not a requirement for a repository/file branch.

## Completion
No slice is complete without verification evidence and a full updated ZIP package.
